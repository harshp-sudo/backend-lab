Resilience & Fault-Tolerance Patterns

A ship has separate compartments, emergency procedures and a captain who stops sending sailors into a flooded room. Repeating a rescue attempt faster is not useful if every attempt blocks the remaining exits.

Fault tolerance starts with the failure model and recovery promise. Breakers stop some calls, bulkheads bound shared resource damage, and disciplined retries recover only within an explicit budget.

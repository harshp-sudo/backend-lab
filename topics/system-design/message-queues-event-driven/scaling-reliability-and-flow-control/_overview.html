Scaling, Reliability & Flow Control

Adding helpers can clear several trays faster, but it cannot split one indivisible task. Broken slips need an owned repair tray, and a full room needs a way to slow new arrivals instead of stacking paper until the exits disappear.

This path connects consumer assignment, failed-message recovery and bounded demand. More consumers, more retries and larger queues are only useful when actual downstream capacity and correctness allow them.

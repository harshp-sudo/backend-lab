Reliability, Security & Traffic Control

A reception desk checks who you are, sends you to the right room, controls the queue and makes sure a repeated form does not create a second appointment. These protections cooperate, but checking a form is different from deciding whether its owner may enter.

This category follows API policy at the boundary and correctness across retries. Each lesson names which component owns a decision and what happens when the network or a dependency fails.
